# Key Press Reaction Lab

## Overview
This project implements a **Key Press Reaction Lab** aimed at measuring a user’s reaction time when responding to letters and numbers. The original lab task focused on recording response speed, but this implementation emphasizes **interaction design and usability**, making the task more engaging and user-friendly.

## Features
- **Random character generation**: Letters (A-Z) or numbers (0-9) appear in a **large, visually prominent box**.
- **User interaction**:
  - Press **A** for letters
  - Press **L** for numbers
  - Press **SPACE** to start a new character
- **Real-time feedback**:
  - Immediate confirmation for correct or incorrect key presses
  - Attempts counter shows progress dynamically
  - Average reaction time calculated at the end
- **End-of-task feedback**: Provides motivational messages based on performance, enhancing user engagement.

## HCI Principles Applied
- **Feedback:** Users receive immediate visual feedback for each key press, reinforcing learning and awareness.
- **Affordance and clarity:** Controls are clearly labeled, visually distinct, and intuitive to use.
- **Visual hierarchy:** The main stimulus (character) is displayed prominently, reducing cognitive load and focusing attention.
- **Progress indicators:** Attempts counter allows users to track their performance in real time.
- **Motivation and engagement:** Fun and interactive feedback (emojis and messages) encourages active participation.

## Purpose
This lab combines **reaction time measurement with HCI principles** to demonstrate how interface design can influence user performance and engagement. It emphasizes clarity, responsiveness, and interaction quality while making a simple task more engaging.
